# CampusBITE app (Expo)

The whole CampusBITE system: Expo Router screens plus Expo API routes backed by SQLite. See the [root README](../../README.md) for layout, commands and the security model, and [DEMO.md](../../DEMO.md) for the demo runbook.

```bash
npm run demo         # expo start --lan --offline
npm run seed         # demo data
npm run reset-admin  # one-time admin password
npm test             # Vitest API tests
```
